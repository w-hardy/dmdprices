# dmdprices — Claude Instructions

## Package Purpose

`dmdprices` is an R package for looking up NHS medicine prices from the **dm+d (Dictionary of Medicines and Devices)**. It bundles a complete dm+d release (~118k AMPPs) and exposes functions for price lookup, dose optimisation, and NHS Cost Inflation Index adjustments.

## Dev Workflow

```r
# Regenerate documentation (roxygen2)
devtools::document()

# Run all tests
devtools::test()

# Full R CMD check
devtools::check()

# Build package tarball
devtools::build()

# Build pkgdown site
pkgdown::build_site()
```

- Docs are generated by **roxygen2** (`RoxygenNote: 7.3.3`, markdown enabled). Always run `devtools::document()` after changing `@` tags or function signatures.
- Tests live in `tests/testthat/`. Run a single file with `devtools::test(filter = "price_lookup")`.
- `data-raw/dmd_master.R` rebuilds the bundled dataset; run it manually then `usethis::use_data(dmd_master, overwrite = TRUE, compress = "xz")`.

## Architecture

```
R/
├── dmd_price_lookup.R      # Core search (partial / exact / fuzzy via stringdist)
├── dmd_dose_optimise.R     # dmd_dose_optimise() + dmd_dose_cost() + memoized prep step
├── dose_combinations.R     # Internal DP solver (.optimise_group, .dp_solve, etc.)
├── parse_strength.R        # Strength parser + preparation classifier
├── dmd_load.R              # Load user-supplied dmdDataLoader CSV folder → <dmd_db>
├── nhscii.R                # NHS Cost Inflation Index rates + inflate helpers
├── apps.R                  # Shiny launcher stubs
├── data.R                  # dmd_master dataset docs
└── utils.R                 # Internal column specs, canonical unit table
```

Key data flow: `dmd_price_lookup()` → `.dmd_prepare_candidates()` (memoized) → `.optimise_group()` (DP) → result tibble.

## Coding Conventions

- **Style:** tidyverse — `|>` pipe, `dplyr`/`tibble`/`stringr`/`cli` throughout.
- **Errors/warnings:** always use `cli::cli_abort()` and `cli::cli_warn()`. Never use bare `stop()` or `message()`.
- **Internals:** prefix with `.` (e.g. `.col_names`, `.unit_table`). Do not export internal helpers.
- **Docs:** roxygen2 markdown. Every exported symbol needs `@param`, `@return`, `@export`, and at least one `@examples` (wrapped in `\dontrun{}` if it needs network/data).
- **Tests:** testthat edition 3. Use the fake fixture `.fake_dose_db()` from `tests/testthat/helper.R` — never depend on external files or real CSVs in tests.
- **Performance-sensitive paths:** use `memoise::memoise()` with `cachem::cache_mem(max_size = 1024 * 1024^2)` for session-level caching.

## Key Internals

| Symbol | File | Notes |
|---|---|---|
| `.dmd_prepare_candidates_memo` | `dmd_dose_optimise.R` | Memoized candidate enrichment (price lookup + parse + classify). Call this, not the bare version. |
| `.optimise_group()` | `dose_combinations.R` | DP optimiser for one preparation group. |
| `.canonicalise_unit()` | `utils.R` | Converts dose values to a canonical (mg) basis. |
| `.classify_preparation()` | `parse_strength.R` | Maps parsed tail strings to `preparation_group` / `preparation_label`. |
| `.empty_dose_result()` | `dmd_dose_optimise.R` | Returns a zero-row tibble with the canonical column schema. |
| `.col_names` | `utils.R` | Named character vector of expected CSV column names for `dmd_load()`. |
